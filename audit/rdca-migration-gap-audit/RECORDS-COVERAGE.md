## Gaps — four datasets

### 1. Most Promising Player — **10 seasons missing** (biggest gap)
Database holds 39 seasons, **1975/76 → 2014/15**. No workbook covers it.
**Missing: 2015/16 through 2025/26.**
→ *Ask RDCA for Most Promising Player winners for the last ten seasons.*

### 2. Board of Management — **3 seasons missing**
Database holds 103 seasons, **1920/21 → 2022/23** — the deepest record in the set.
**Missing: 2023/24, 2024/25, 2025/26.**
→ *Ask for office bearers (President, VPs, Secretary, Treasurer, Records, Operations) for the last three seasons. The current board is already on `board.html`; this is the historical series.*

### 3. Life Members — **needs confirmation, not necessarily a gap**
Database holds 52 seasons of appointments, **1927/28 → 2019/20**, plus Graeme Seymour and Sean Flynn (2024/25) added by hand — **59 members, 56 with write-ups**.

Seasons with no appointment recorded since 2015/16: 2016/17, 2017/18, 2018/19, 2020/21, 2021/22, 2022/23, 2023/24, 2025/26.

**Life members aren't appointed every year, so most of these are probably legitimate blanks.**
→ *Ask RDCA to confirm which of those seasons had appointments, and supply write-ups for Seymour and Flynn.*

### 4. Junior Best Player — **1 season missing**
Workbook covers 2015/16 → 2024/25; the 2025/26 cell is blank.
→ *Ask for the 2025/26 Junior Best Player.*

## Also outstanding

**28 life-member photographs.** Filenames are in the database (`cahochkins.jpg` and similar) but the files aren't served from any reachable path on `honours.rdca.com`, and the `?ID=lifemember` endpoint returns an empty page. → *Ask for the image directory from the same hosting account.*

**The database itself is behind.** The site is now current because the workbooks fill the recent seasons, but `honours.rdca.com` still ends at 2020/21 for premierships and 2015/16 for averages. If that database remains the system of record, it needs the last five seasons entered — otherwise the workbooks become the de facto source and the two will drift.
